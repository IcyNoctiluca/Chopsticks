# Phase 06 - Local app

**Depends on:** Phase 05

**Outcome:** A polished local two-player application built on the stable engine.

## Work

- Choose the target platform and build the smallest usable graphical client.
- Show player hands, active player, legal selection state, redistribution flow, game result, restart, undo, and rules.
- Render animations from engine results only.
- Add accessibility basics: readable contrast, non-colour move cues, focus/touch support, and clear turn announcements.
- Playtest the interface with new players and record confusion points.

## Exit criteria

- Two people can start, finish, restart, and undo a local game without developer tools.
- The app uses the public engine/session APIs; it has no duplicate rules logic.
- Key local flows are tested and manually checked for accessibility.
