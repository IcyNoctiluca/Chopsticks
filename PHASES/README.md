# Phases

This folder is the execution path for Chopsticks. Start with `00-rules-decision.md` and only advance when the current phase's exit criteria are met.

The sequence intentionally proves the game before expanding its surface area:

```text
Decide rules -> Specify -> Engine -> Test + CLI -> Analyse + freeze
    -> History + AI -> Local app -> Online play + release
```

Record evidence, decisions, and blockers in the repository-level `PROGRESS.md`.
